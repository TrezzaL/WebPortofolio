# Choirul Rizal — Personal Portfolio

Portofolio modern berkinerja tinggi yang menggabungkan showcase software engineering dan karya video editing/animasi. Dibangun menggunakan Astro dan Tailwind CSS v4, serta di-deploy pada platform Vercel.

---

## ⚡ Tech Stack
* **Framework:** [Astro](https://astro.build/)
* **CSS Framework:** [Tailwind CSS v4](https://tailwindcss.com/)
* **Email Gateway:** [Resend](https://resend.com/)
* **Deployment:** [Vercel](https://vercel.com/)

---

## 🚀 Memulai Pengembangan Lokal

### 1. Prasyarat
* Node.js versi 18+ atau 20+
* Package manager `npm`

### 2. Instalasi & Menjalankan Project
```bash
# Clone repositori
git clone [https://github.com/username/project_portofolio.git](https://github.com/username/project_portofolio.git)
cd project_portofolio

# Install dependencies (jika baru di-clone)
npm install

# Jalankan server lokal
npm run dev
